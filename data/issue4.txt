## 기능 개요

설정한 기간 동안의 내 Jira 이슈를 조회하여, AI가 주간보고 초안을 자동 생성해주는 기능

---

## 확정 스펙

### 양식 A — 서비스요청관리
```
{제목} ({생성일}~)
- 요청자 : {reporter}
- 내용 : 1) description AI 요약
         2) ...
- 진행 : AI가 현재 상태 보고 생성 (~{합의완료일 or 직접입력})
```

### 양식 B — 변경관리
```
{제목} ({생성일}~)
- 요청자 : {reporter}
- 내용 : description AI 요약 한줄
- 진행 :
  (M/D) 워크플로우 댓글 한줄 요약  ← 조회 기간 내 댓글만 필터
  (M/D) ...
  (~{합의완료일 or 직접입력})
```

---

## 공통 규칙

| 항목 | 내용 |
|------|------|
| 이슈 유형 | 서비스요청관리 → 양식A / 변경관리 → 양식B |
| 그룹 | 검토중 / 진행중 / 완료 (사용자 설정 매핑 테이블 기준) |
| 완료 이슈 | 동일 양식 적용, 완료 섹션에 표시 |
| 목표일 | Jira 합의완료일 필드 우선 → 없으면 UI에서 직접 입력 |
| 댓글 필터 | 조회 기간 내 댓글만 (워크플로우 자동 댓글 포함) |
| AI 역할 | description 요약, 상태 기반 진행 문구 생성, 댓글 한줄 요약 |

---

## UI 구성

- **새 탭**: 📊 주간보고
- **기간 설정**: 날짜 직접 입력 (from ~ to)
- **상태 매핑 테이블**: 환경설정에서 Jira 상태명 → 검토중/진행중/완료 매핑
- **합의완료일 없을 때**: 이슈별 목표일 직접 입력 필드 노출
- **출력**: 화면에 텍스트로 표시 + 📋 전체 복사 버튼

## 데이터 출처

| 필드 | Jira 데이터 |
|------|------------|
| 제목 | summary |
| 생성일 | created |
| 요청자 | reporter |
| 내용 | description → AI 요약 |
| 진행 (양식A) | 현재 상태명 → AI 생성 |
| 진행 (양식B) | 기간 내 댓글 목록 → AI 한줄 요약 |
| 목표일 | 합의완료일 커스텀 필드 → 없으면 직접 입력 |
