🚀 스벅 Jira 도우미 — 사용 가이드

이 문서는 스벅 Jira 도우미 웹 앱의 주요 기능과 사용 방법을 소개합니다.
AI(Gemini) 기반의 JQL 자연어 검색, 유사 이슈 탐색, 처리 마법사 등 업무 효율을 높이는 핵심 기능을 단계별로 안내합니다.

📌 접속 URL: 사내 Docker 서버에서 실행 중인 앱에 접속합니다. (예: http://<서버IP>:8765)
설정 화면에서 Gemini API Key와 Jira PAT Token을 먼저 등록해야 모든 기능을 사용할 수 있습니다.

1. 앱 개요

스벅 Jira 도우미는 Jira 업무 처리를 AI로 가속화하는 사내 도구입니다.

기능설명사이드바 탭
🤖 AI 채팅 자연어로 Jira 이슈를 검색 · 요약 · 분석 안내데스크
⚙️ 환경 설정 API Key · PAT Token · 대상 사용자 등록 환경설정
🔍 Jira 검색 JQL 직접 실행 및 결과 확인 Jira 테스트
🔗 유사 이슈 임베딩 기반 유사 이슈 자동 탐색 유사이슈검색
🪄 처리 마법사 이슈 유형별 처리 초안 AI 자동 생성 처리마법사

▲ 앱 홈 화면 (안내데스크 탭)

2. 초기 환경 설정

⚠️ 필수 작업: 아래 두 가지 Key를 등록하지 않으면 AI 기능이 동작하지 않습니다.

2-1. Gemini API Key 등록

1 사이드바에서 환경설정 탭 클릭
2 Gemini API Key 발급 링크를 클릭하거나, 기발급된 Key를 입력
3 저장 버튼 클릭 → 화면 상단에 저장 완료 메시지 확인

2-2. Jira PAT Token 등록

1 Jira → 프로필 아이콘 → Profile → Personal Access Tokens에서 Token 생성
2 환경설정 화면에 Token 및 Jira Base URL 입력 후 저장
3 ⚡ 연결 확인 버튼으로 연결 상태 검증

2-3. 대상 사용자 설정

유사 이슈 검색의 기준이 될 사용자(최대 3명)를 사번으로 등록합니다.

▲ 환경설정 화면

3. AI 채팅 (Jira 검색)

자연어로 질문하면 Gemini AI가 JQL로 변환해 Jira를 검색하고 결과를 요약합니다.

사용 예시

💬 "최근 내가 담당한 오류 이슈 찾아줘"
💬 "이번 주 완료된 변경관리 이슈 목록 보여줘"
💬 "JIRA-1234 이슈 상태 확인해줘"
1 사이드바에서 Jira 테스트 탭 클릭
2 하단 입력창에 질문 입력 후 Enter 또는 전송 버튼 클릭
3 AI가 JQL을 생성해 검색 후 결과를 카드 형태로 표시
4 이슈 키 클릭 → Jira 원본 페이지로 바로 이동
📝 채팅 내용은 브라우저를 닫아도 localStorage에 보존됩니다.
새로고침 후에도 이전 대화가 유지됩니다.

4. 유사 이슈 검색

현재 담당 이슈와 임베딩(Embedding) 유사도가 높은 과거 이슈를 자동으로 찾아줍니다.
유사 이슈의 처리 내용을 참고해 현재 이슈를 더 빠르게 해결하세요.

캐시 구축 (최초 1회)

1 유사이슈검색 탭 클릭
2 🔄 서비스요청관리 또는 🔄 변경관리 버튼으로 이슈 유형별 캐시 구축
3 진행 상황은 실시간 프로그레스 바로 확인 가능 (수백 건은 수 분 소요)
⏱️ 첫 캐시 구축은 이슈 수에 따라 수 분이 걸릴 수 있습니다.
이미 구축된 캐시는 ./data/embedding_cache.db에 저장되어 재시작 후에도 유지됩니다.

유사 이슈 검색

1 미해결 이슈 목록에서 이슈 키를 클릭하거나 검색창에 이슈 키 입력
2 유사도 높은 이슈가 이슈 유형별 섹션으로 정렬되어 표시
3 각 유사 이슈 카드에서 💬 댓글 / 🔄 상태 등 인라인 액션 바로 실행 가능

▲ 유사 이슈 검색 결과 화면 (이슈 유형별 아코디언)

5. 처리 마법사

이슈 키를 입력하면 AI가 처리 내용 초안을 자동으로 작성합니다.
변경관리·서비스요청관리 이슈 모두 지원하며, 업무 유형에 맞는 항목이 자동 추출됩니다.

지원 이슈 유형

이슈 유형지원 항목
변경관리 배포절차 / 결제멘트 / 영향도 분석 / 롤백 계획 등 6종 양식
서비스요청관리 계정·권한 처리 / 데이터 추출 / 공통코드 변경 / 기타 — 4종

사용 방법

1 사이드바에서 처리마법사 탭 클릭
2 이슈 키 입력 후 이슈 감지 버튼 클릭
3 이슈 정보 확인 → 업무 유형 선택(서비스요청관리의 경우) → 초안 생성 버튼 클릭
4 생성된 초안을 검토 후 Jira에 댓글로 복사하여 사용
💡 유사 이슈와 연동: 유사이슈검색 화면에서 🪄 마법사로 열기 버튼을 클릭하면
해당 이슈 키가 자동 입력된 채로 마법사 탭이 열립니다. (예정 기능)

6. 유용한 팁

🌙 다크/라이트 모드

사이드바 하단의 테마 토글 버튼으로 전환합니다. 설정은 localStorage에 저장되어 재접속 후에도 유지됩니다.

📌 설정 영속성

API Key, PAT Token, 대화 내용 모두 브라우저 localStorage에 저장됩니다.
같은 브라우저에서는 재접속 후에도 설정이 유지됩니다.

🔗 이슈 키 링크

검색 결과의 모든 이슈 키를 클릭하면 Jira 원본 페이지로 바로 이동합니다.

⚡ 연결 확인

환경설정에서 ⚡ 연결 확인 버튼으로 Jira 연결 상태를 언제든 검증할 수 있습니다.

7. FAQ

질문답변
AI 응답이 없거나 오류가 발생해요 환경설정에서 Gemini API Key가 올바르게 등록되어 있는지 확인하세요. API 사용 한도 초과 시 403 오류가 발생할 수 있습니다.
Jira 연결이 안 돼요 PAT Token 만료 여부를 확인하세요. 토큰을 재발급 후 환경설정에서 업데이트 하세요.
캐시 구축이 너무 오래 걸려요 이슈 수가 많을수록 시간이 소요됩니다. 한 번 구축된 캐시는 서버 재시작 후에도 유지되므로 첫 구축 이후에는 빠릅니다.
설정이 저장되지 않아요 브라우저의 localStorage가 비활성화되어 있거나 시크릿 모드를 사용 중인지 확인하세요.
대화 내용을 초기화하고 싶어요 채팅 화면의 대화 초기화 버튼을 클릭하거나, 브라우저 개발자 도구에서 localStorage를 지우세요.
