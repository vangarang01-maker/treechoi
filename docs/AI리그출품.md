업무 문제 정의(왜 했나요?)	
 1. 반복적인 Jira 이슈 분석 및 유사 사례 탐색의 리소스 낭비를 제거하고 업무 생산성을 극대화하기 위함.
 2. 기존 MCP 솔루션의 실무 한계를 개선하고, 직관적인 현장 맞춤형 UX를 제공하기 위함.

사용 도구(뭘로 만들었어요?)	
 Python 3, HTML/CSS/JS, Gemini API, DevX 커스텀 에이전트

한줄 소개	
 Jira 참고 이슈 검색 및 초안 자동 작성 기능을 제공하는 AI 기반 지능형 어시스턴트.

성과(근거 포함)
 임베딩 기술 기반 유사 이슈 검색 정확도 향상 및 소요 시간 획기적 단축. 대화형 인터랙션을 통한 부서 내 업무 숙련도의 상향 평준화 달성.

적용 방법(다른 사람이 베끼려면 어떻게 해요?)	
 Jira REST API와 사내 'DevX 커스텀 에이전트'를 연동하여 웹 UI에 실시간 분석 결과를 바인딩.

확산 가능성(누가 어떻게 쓸 수 있을까요?)	
 설치가 필요 없는 웹 기반 서비스로 브라우저를 통해 즉시 접근 및 활용 가능.

보안 체크(필요한지, 했으면 뭘 했는지)	
 API Key는 브라우저 로컬 저장소에서 관리하며, 사내망 내 로컬 구동 방식으로 데이터 유출을 원천 차단.


제목 : 지능형 Jira 어시스턴트 웹 서비스 개발

내용 :
기존 범용 MCP 도구의 근본 한계(CLI 조작 복잡성)를 해소하기 위해, 설치 없이 사내망 브라우저에서 즉시 사용 가능한 웹 기반 Jira AI 어시스턴트 자체 개발.

용례1(참고이슈검색) : 담당자에게 미해결 이슈 발생 → AI가 과거 유사 완료 티켓을 자동 탐색
용례2(처리마법사) : 미해결 티켓의 설명을 참조해 현재 이슈에 바로 붙여넣을 수 있는 처리 내용 초안을 즉시 생성
용례3(주간보고서) : 기간별 이슈를 분석해 주간보고서 초안을 즉시 생성

효과 : 유사 이슈 탐색 및 처리 초안 작성 시간을 건당 평균 수십 분에서 수 분 이내로 단축. 숙련자의 과거 처리 노하우가 AI를 통해 팀 전체에 실시간 공유되어 신규·기존 담당자 간 업무 숙련도 격차 해소. 설치 불필요한 웹 서비스 특성상 전사 확산 시 별도 클라이언트 배포 비용 없음.
